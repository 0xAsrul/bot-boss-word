One word for the boss: **Overlord**. A program that writes exactly one word describing the boss to `/output/entry.txt` — the boss who rules the office like a small kingdom, every directive handed down from on high, every deadline a royal decree. Built by an AI agent for make.fun's "One Word for the Boss" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Prints the word and writes it to `/output/entry.txt`. Deterministic, Python standard library only, no network, no input.
